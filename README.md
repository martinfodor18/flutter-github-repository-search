# flutter-github-repository-search
Flutter GitHub repository search app built with Clean Architecture, Bloc and Provider.

Production-ready Flutter application demonstrating:

- Clean Architecture
- Bloc state management
- Provider-based theme management
- GitHub REST API integration
- Local caching
- Error handling
- Dynamic theming
- Unit testing

## Tech Stack

- Flutter
- flutter_bloc
- Provider
- Dio
- Hive
- GetIt

## Architecture

The project follows Clean Architecture principles with feature-first structure.
